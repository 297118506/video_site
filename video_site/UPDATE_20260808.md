# 更新说明 - 2026-08-08

## 新增功能：短视频分类 + 短·分类管理

本次更新围绕**短视频分类独立化**和**短视频模块体验优化**展开，核心改动是：为短视频建立独立的分类体系（short_categories），与原有的视频分类（categories）完全隔离，互不干扰。

---

## 一、短视频模块改造

### 1.1 路由变化

| 原路由 | 新路由 | 说明 |
|--------|--------|------|
| `/shorts` (直接播放) | `/shorts` | 分类列表页（先选分类再播放） |
| — | `/shorts/play` | 播放所有短视频（= 点击"全部"） |
| — | `/shorts/play/<category_id>` | 播放指定短分类中的短视频 |

### 1.2 短视频分类列表页 (/shorts)

- 页面顶部大标题「短视频分类」
- 网格卡片布局，自适应列数
- 第一张卡片固定为「全部」橙红渐变配色，显示总视频数量
- 其它分类按"父分类→子分类"顺序展示
- 父分类会统计其子分类的视频总数，并显示「含子分类」标签
- 卡片悬浮上浮效果，视觉体验更好
- 空状态时引导用户「去后台创建分类」或「直接播放全部」

### 1.3 播放页增强 (/shorts/play/<category_id>)

- 顶部栏**左侧**新增：
  - 返回按钮（←）：返回分类列表
  - 当前分类标签（图标 + 名称）
  - 分类下拉选择器：不离开播放页即可切换到其它分类
- 顶部栏**右侧**保持不变：自动切换开关、随机播放开关、进度指示 (1/N)
- 顶部栏布局由 `justify-content: center` 改为 `space-between`

## 二、后台管理：短·分类管理

### 2.1 菜单位置

在**所有后台页面**的侧边栏，「分类管理」下方新增「短·分类管理」（图标 `bi-folder-symlink`）：


### 2.2 功能特性

与「分类管理」完全一致，但操作的是独立的 `short_categories` 表：

- 添加分类（支持父子层级、排序）
- 列表层级展示（父分类加粗，子分类缩进显示「├─」）
- 单个删除 + 批量删除（带确认提示）
- 分页（每页 20 条）
- 删除分类时会同时删除该分类下的短视频（仅 `is_short_video=1` 的记录，不影响普通视频）

### 2.3 标题说明

短·分类管理页面标题带副标题提示：
> 短·分类管理（仅用于短视频模块，与普通分类互不干扰）

### 2.4 短视频管理页面联动

- 「短视频管理」列表页的分类筛选，下拉选项变为**短分类**
- 「添加短视频」表单的分类选择框，变为**短分类**
- 「编辑短视频」表单同上

## 三、OpenList 导入：分类选择联动

### 3.1 自动切换分类源

根据「导入到模块」下拉的选择，自动切换分类下拉的选项：

| 导入到模块 | 分类下拉源 | 标签文字 |
|-----------|-----------|---------|
| 全部视频（和首页） | `categories` 表（原分类管理） | 「导入到分类」 |
| 仅短视频模块 | `short_categories` 表（短·分类管理） | 「导入到短·分类」 |

### 3.2 实现细节

- 页面加载时：注入两个全局变量 `videoCategories` 和 `shortCategories`
- `switchCategorySource()` 函数：根据当前模块值重建 `<select>` 的 `<option>`
- `DOMContentLoaded` 阶段调用一次，保证初始态正确
- 模块 change 事件中再次调用
- 刷新分类按钮 (`refreshCategories()`) 也会根据模块调用对应 API：
  - 全部视频 → `GET /api/categories`
  - 短视频模块 → `GET /api/short_categories`

### 3.3 原有功能保持

- 切换到短视频模块仍然会：
  - 禁用/取消「自动创建系列」复选框
  - 隐藏文件列表中的图片
  - 禁用封面选择

## 四、APP 开放 API 新增接口

### 4.1 `/api/v1/short_categories` (新增)

获取短视频分类树，返回分类、每个分类的视频数量统计，以及短视频总数。

```
GET /api/v1/short_categories
```

响应:
```json
{
  "success": true,
  "categories": [
    {
      "id": 1, "name": "搞笑", "parent_id": 0, "sort_order": 0,
      "children": [
        {"id": 3, "name": "街头采访", "parent_id": 1, "children": []}
      ]
    }
  ],
  "total_short_count": 160,
  "category_counts": {"0": 5, "1": 120, "3": 35}
}
```

### 4.2 `/api/v1/shorts` 增强 (category_id 参数)

```
GET /api/v1/shorts?category_id=1&per_page=500
```

| 参数 | 默认 | 说明 |
|------|------|------|
| `category_id` | 0（全部） | 短视频分类 ID，对应短分类表中的 id |
| `page` | 1 | 页码 |
| `per_page` | 20 | 每页数量，最大 500 |
| `q` | - | 搜索关键词（同时匹配 title 和 description） |

### 4.3 全部 V1 API 汇总

| 接口 | 说明 |
|------|------|
| `GET /api/v1/categories` | 普通视频分类树 |
| `GET /api/v1/short_categories` | 短视频分类树 + 数量统计 (新增) |
| `GET /api/v1/videos` | 普通视频列表 |
| `GET /api/v1/videos/<id>` | 视频详情 |
| `GET /api/v1/shorts?category_id=...` | 短视频列表，支持短分类筛选 (增强) |
| `GET /api/v1/series` | 系列列表 |
| `GET /api/v1/series/<id>/episodes` | 系列分集 |
| `GET /api/v1/stats` | 统计数据 |
| `GET /api/v1/search?q=&type=all|video|shorts` | 全局搜索 |

## 五、数据库变更

### 5.1 新增表 `short_categories`

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER PK | 自增 |
| name | TEXT NOT NULL | 分类名称 |
| slug | TEXT UNIQUE | URL 友好标识 |
| parent_id | INTEGER DEFAULT 0 | 父分类 ID (0=顶级) |
| sort_order | INTEGER DEFAULT 0 | 排序权重 |
| created_at | TIMESTAMP | 创建时间 |

与 `categories` 表结构完全相同，但独立存在。应用启动时通过 `CREATE TABLE IF NOT EXISTS` 自动创建，无需手工迁移。

### 5.2 videos 表结构不变

- `category_id` 仍然使用同一列，但语义根据 `is_short_video` 的值自动区分：
  - `is_short_video=1` 的视频 → `category_id` 指向 `short_categories.id`
  - `is_short_video=0` 的视频 → `category_id` 指向 `categories.id`
